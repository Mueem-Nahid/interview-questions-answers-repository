## How to use

1. Choose the guide that matches the role or interview round.
2. Practice answering each question aloud before reviewing the sample answer.
3. Adapt examples to your actual experience and avoid claiming project details you did not own.
4. Add follow-up questions and lessons learned to the relevant guide after interviews.

## Candidate-specific materials

The AI Engineer guide is tailored to the candidate profile and projects described in the supplied résumé and portfolio. Source files and other private or local reference materials belong in `data/`; Git ignores that directory. Keep any shareable preparation content in the Markdown guides.

## Contributing

Use Markdown headings to organize topics, keep answers concise enough to practice, and include code or diagrams when they clarify an explanation. Add new guides to the table above.
